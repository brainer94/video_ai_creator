# ASET

## Fungsi tampilan

Tab `Aset` menampilkan semua gambar, audio, dan video yang tersedia pada adegan aktif. Tab ini menjadi tempat utama untuk memeriksa hasil proses dan memilih file yang akan digunakan pada pengaturan adegan.

## Alur kerja singkat

1. Pilih adegan pada daftar di sisi kiri.
2. Buka tab `Aset`.
3. Cari file yang ingin digunakan.
4. Klik satu kali untuk melihat informasinya.
5. Klik ganda gambar atau video untuk menampilkan pratinjau.
6. Pilih file tersebut dari tab proses yang membutuhkannya.

## Daftar aset

Daftar dapat berisi:

- gambar hasil `Gambar Awal` atau `Prompt Tambahan`;
- gambar hasil `Image Edit`;
- gambar yang digunakan sebagai referensi video;
- audio speech atau audio referensi;
- video hasil proses atau video referensi.

File yang baru dibuat akan muncul setelah proses selesai dan daftar aset diperbarui.

## Informasi dan pratinjau

Saat sebuah file dipilih, bagian informasi menampilkan keterangan file tersebut.

Klik ganda gambar untuk melihat gambar dengan ukuran yang lebih besar. Klik ganda video untuk memutarnya pada panel pratinjau. Audio juga dapat dipilih untuk melihat informasinya.

Panel pratinjau hanya ditampilkan ketika tab `Aset` sedang dipilih. Saat tab lain aktif, ruang tersebut dikembalikan ke area kerja utama agar editor menjadi lebih lebar.

## Menggunakan aset pada proses lain

Pilih file dari daftar pilihan pada tab yang sesuai. Contohnya:

- gambar awal digunakan oleh MiniMax H3 I2V, S2V, `i2v`, `image_pan`, dan `image_zoom`;
- gambar, audio, dan video dapat dipilih sebagai referensi pada MiniMax H3 R2V;
- gambar dipilih sebagai bahan edit pada `Image Edit`.

Untuk `i2v` biasa, semua gambar yang berada langsung di folder aset utama dapat digunakan dan urutannya mengikuti nama file secara alfabetis. Gunakan nama dengan awalan angka bila urutan gambar penting.

## Catatan

Pastikan adegan yang aktif benar sebelum memilih file. Aset dari adegan lain tidak digunakan sebagai pilihan pada adegan yang sedang dibuka.
