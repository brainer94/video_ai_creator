# PROMPT TAMBAHAN

## Fungsi tampilan

Tab `Prompt Tambahan` menyediakan tiga ruang terpisah untuk membuat gambar pendukung atau variasi gambar. Gambar dari setiap ruang disimpan sebagai aset pada adegan aktif dan tidak menggantikan gambar awal utama.

## Alur kerja singkat

1. Pilih salah satu bagian `Prompt Tambahan 1`, `Prompt Tambahan 2`, atau `Prompt Tambahan 3`.
2. Isi `Prompt Positif` dan, bila perlu, `Prompt Negatif`.
3. Tekan `Buat Prompt` bila ingin meminta bantuan Gemini.
4. Periksa hasil prompt.
5. Tekan `Buat Image` pada bagian yang sama.
6. Buka tab `Aset` untuk memeriksa gambar yang dihasilkan.

## Isi setiap bagian

### Prompt Positif

Jelaskan gambar pendukung yang ingin dibuat, termasuk subjek, penampilan, suasana, lokasi, komposisi, dan detail yang harus dipertahankan.

### Prompt Negatif

Tuliskan hal-hal yang ingin dihindari pada gambar tersebut. Kosongkan bila tidak ada batasan tambahan.

### Buat Prompt

Meminta Gemini membantu menyusun prompt berdasarkan instruksi yang sudah ditulis. Fitur ini bersifat pilihan; prompt dapat ditulis dan diedit langsung.

### Buat Image

Membuat gambar untuk bagian tersebut. Pastikan tombol yang ditekan berada pada bagian prompt yang benar karena setiap bagian diproses secara terpisah.

## Mengatur hasil gambar

Setelah gambar selesai dibuat, periksa namanya pada tab `Aset`. Bila gambar-gambar ini akan dipakai pada `i2v` biasa, semua gambar yang berada langsung di folder aset utama dapat digunakan dan urutannya mengikuti nama file secara alfabetis.

Jika urutan gambar penting, gunakan awalan nama seperti `01_`, `02_`, dan `03_` agar urutannya jelas.

## Catatan

Tab ini tidak wajib digunakan. Gunakan hanya bila adegan membutuhkan gambar pendukung, variasi, atau beberapa gambar untuk video berbasis rangkaian gambar.
